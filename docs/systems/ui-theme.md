# Menu theme

[USER] 2026-10-30: every menu looks consistent (the Lodestone menu, character sheets, the pack, options, dialogues, the world map UI), with variety where needed.

- [USER] 2026-10-30 (menu-style-go): "lets build the menus in-engine so we can more easily animate them and stuff." So the look is drawn in code by `UiTheme`: the palette (the leaf frame's deep green, parchment rules and plates, blue diamonds, Young Serif) in one constant block, panels as `FramedBox` (fill, double rule, corner diamonds), `UiTheme.frame/plate/diamond` for screens that paint themselves, and `pop_in`/`pop_out`/`fade_in` for opening and closing. The art runner's pitch is the target to match in code; a painted piece only where one truly needs painting.
- `UiTheme.make()` (`game/scripts/ui/ui_theme.gd`) builds the one shared Theme. `Game._ready` merges it into the engine's default theme, which every Control without its own theme falls back to. (A theme on the root window doesn't reach Controls under a CanvasLayer, which is where all the HUDs live.)
- Use these instead of hand-made styles: `theme_type_variation` `DialogPanel` (dialogues, the Lodestone menu, PACK), `MenuPanel` (small menus by a piece, the fight's action bar), `InfoPanel` (forecasts, read-outs), `TipPanel` (hover cards; Godot's own tooltips match), and for Labels `MenuTitle` and `SubTitle`. Buttons need nothing.
- On it now: explore and overworld dialogues (they pop open and fade shut), the Lodestone menu, PACK, the options screen, the character sheet (draws with `UiTheme.frame/plate/diamond`, fades in), and the fight's menu, forecast and action layouts.
- Left alone on purpose: the launch screen and the village (`RisoTheme`) and the painted bottom frame.
- Art: when Brandon picks the art runner's menu style, its nine-slice pieces go in `game/art/source/ui/menu/` under the names in `UiTheme.PIECES` (`panel.png`, `panel_small.png`, `panel_info.png`, `tooltip.png`, `button*.png`) and replace the flat boxes with no code change; the margin per piece is in the same table.
- Options (`AdventureMenu.options`, OPTIONS on the Lodestone menu): the fight menu's layout and big screen / small window, saved in `Game.meta.settings` (`Game.set_setting`).
