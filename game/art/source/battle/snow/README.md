# snow tile set

Drop snowy versions of the battle art here with the same file names as the folder above
(`top_grass.png`, `side_cliff.png`, `prop_pine_1.png`, ...). Anything missing here falls back
to the base file, so replace them one at a time. Pick the set in the sandbox (right panel,
"tile set"). Any new subfolder becomes a set the same way (`dungeon/`, `forest/`).
Sizes and rules: docs/art/battle-maps.md.
