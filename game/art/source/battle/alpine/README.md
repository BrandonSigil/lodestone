# alpine tile set

A mix-and-match set with no art of its own: `data/battle_art_alpine.csv` takes the forest tops,
grey stone cliffs (`side_masonry`) and the snow set's pines (`snow/prop_pine_1`), to match the
mountain valley reference (green meadows, grey cliffs, snowy pines). Drop a file here with a base
name (`side_cliff.png`, `top_grass.png`...) and it replaces the borrowed one for this set.
Design: docs/design/map-look.md.
